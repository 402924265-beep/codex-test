# 制造费计算知识库（供 DeepSeek 指标问答使用）

来源：Basic Memory 中《制造费跨任务通用口径》《三张表数据口径与历史决策》《产协会资料运行手册》《生产周总结运行手册》《制造费三张表网站当前状态》，以及本工作台已实现并验证的计算口径。本文只保留制造费计算、解释和数据边界，不含密码、密钥、账号凭据或个人信息。

## 1. 证据优先级

1. 当前页面随问题发送的本地确定性计算结果和月度明细。
2. 用户当轮明确确认、当期批准的数据源和最新复核工作簿。
3. 最近一次实际成品及可核验脚本。
4. Basic Memory 与 00 知识库中的历史材料。

历史材料只用于解释口径和风险。与当前页面数据冲突时，以当前页面的工厂、年份、期间、实际/预测边界和数值为准。

## 2. 期间和场景

- 已关账并收到正式来源的月份才叫实际；未来月份只能叫预算、预测或管理情景。
- 同期、预算、目标、滚动预测、管理调整和实际必须分开，不得混写。
- 4+8、5+7、6+6、7+5是具体期间的预测版本，不是永久规则。
- 累计只到用户选择的月份；累计单台必须用累计费用除以累计产量重算，不能累加或平均月度单台。
- 页面选择的工厂、年份、当月/累计和月份是查询唯一范围。问题文字若与选择冲突，以选择为准并提示范围。

## 2.1 成本指标词典与自然语言映射

以下词典由00知识库的《制造费科目与计算逻辑》《制造费项目记忆库》以及 Basic Memory 的《制造费跨任务通用口径》《三张表数据口径与历史决策》整理。词典只负责解释和识别；金额仍由本地确定性引擎计算。

- 制造费、制造费用、制造费用总额、总制造费：制造费总计。总计包含制造主段和G&A/GMA外围段，但每个区域只汇总一次。
- 固定费用、固定制造费：折旧（含FC）、运营费、存货跌价准备、固定能源、间接人工、白领固定人工、半固定以及分配费用总计。
- 变动费用、变动制造费：直接人工、报废/可回收废料、生产耗用品、废料销售/回收收益和变动能源。
- 折旧、折旧费、摊销：折旧（含FC）。折旧实际需要叠加对应FC；非折旧科目不得叠加FC。
- 直接人工、一线人工：制造费主段直接人工大科目；直接员工、一线人数是人数指标，不能与人工费用混用。
- 间接人工、辅助人工：制造费主段间接人工大科目；间接员工、辅助人数是人数指标。
- 固定人工、白领人工、管理人工：制造费主段固定人工-白领；白领人数、管理人数是人数指标。
- 工资、薪资、Salary：工资小科目；公司人工成本还包括工资、加班、税费、保险、计提、补偿、激励和同一人工大科目内的抵减项。
- 运营费、组织运营费：CS_FIX COST。
- 半固定、半固定费用：CS_SEMIFIX，包括班车、工作服、餐费、维修等该段正式列示的小科目；不能仅凭名称把其他段科目搬入半固定。
- 班车、出租车、本地交通：半固定段班车和出租车小科目。工作服、劳保服是工作服小科目；工作餐、食堂费、餐费是工作餐小科目。
- 生产耗用品、生产耗用、低值耗用、物耗：CS_VARIABLE COST。物耗默认映射到生产耗用品，不自动包含报废损失。
- 报废、废料损失：CS_SCRAP_VARIABLE。原材料报废、半成品报废、成品报废分别列示；它们不是正常生产耗用品。
- 可回收废料、废料销售、废品收入、回收收益：按当前三张表对应的废料损失或收益科目解释，收益与费用不得混为同一方向。
- 固定能源、固定能源费与变动能源、变动能源费是两个不同大科目；电费、水费、油气费是能源小科目，必须先确认所在大科目。
- 存货跌价准备、库存跌价准备、原材料减值准备：当期费用发生额；不是超期库存余额。
- 产量、订单量、定单量、自然台、标准台：业务量指标。自然台与标准台口径不同，来源未明确时不能互换。
- 产值、收入、销售收入：制造费率分母；正式收入未提供时不得由其他指标反推。
- 单台、单位成本、€/台：期间费用乘1000除以期间产量。累计单台必须用累计分子、分母重算。
- 制造费率：制造费除以产值或收入；必须说明正式分母。
- UPPH、人效：产量除以直接人工和间接人工的总人时，白领不进入分母。
- 当月、本月：所选月份单月；累计、截至、1—N月：从1月到所选月逐月汇总；同期是2025年同范围，不是预算。
- 预算、目标、滚动预测、管理调整、实际、同期是不同场景，禁止混写或互相替代。

识别规则：小科目的唯一业务身份是“业务区域＋管理大科目＋SAP编码”，不能只按SAP编码去重。完整10位SAP编码优先表示单个小科目；明确完整中文或源表英文小科目名称时查该小科目；“所有、全部、合计、汇总、各科目”表示复合汇总。同一编码或名称在不同管理大科目出现时，必须让用户选择管理行，不能自动相加；口径仍不唯一时必须先提问，不能静默选择一个近似科目。

## 2.2 半固定维修费用

“维修费、维修费用、所有维修费科目、维修类费用”默认表示半固定维修费用复合指标，不等于单独名为“维修费”的一条小科目。

- 只在制造费主段的CS_SEMIFIX/半固定段内识别。
- 该段内中文名称含“维修、维护、修理”或英文名称含“Repair、Maintain、Maintenance”的小科目全部计入。
- 建筑及办公室维修、工装及设备维修、车辆维修、机器设备维修、单独维修费等，只要实际位于半固定段就计入。
- IT硬件维修也遵守同一判断：位于半固定段才计入；位于运营费或G&A段时不并入半固定维修合计，但可单独查询。
- G&A/外围段出现同名维修小科目时，必须留在G&A，不得混入半固定维修合计。
- 用户给出完整SAP编码或明确完整小科目名称时，可以单独查询该科目；否则“维修费”按复合指标回答。

## 2.3 G&A、GMA与外围段

G&A、GMA、Out of Perimeter、外围段属于独立业务区域。主制造费大科目与G&A中出现的同名小科目不是同一口径。

- G&A区域内的所有小科目都归属于G&A这一条，不因名称中出现维修、IT、人工、能源等词而并入主段对应大科目。
- 查询主段大科目或复合指标时必须排除G&A同名小科目；问题明确写G&A/外围段时才进入G&A范围。
- 查询G&A总额时使用正式G&A小计一次；子项只用于展示、解释和核对，不能再与G&A小计重复相加。
- 制造费总额需要包含G&A/GMA时，也只把正式G&A/GMA总计计入一次。
- G&A固定人工与制造费主段“固定人工-白领”严格分开。G&A白领人工费用金额按G&A段内白领工资、追加激励、工资税、工资计提、失业保险和离职补偿六类科目汇总；费用金额可以逐月及累计回答。G&A人均另需月度有效人数，人数缺少时只能拒绝人均，不能据此拒绝费用金额。

## 2.4 防差错与防猜测

- 逐月表、累计金额和确定性结论必须来自同一个本地计算对象；任意两处金额不一致时，禁止输出业务结论，并要求用户明确工厂、期间或科目口径。
- DeepSeek不得自行挑选小科目、从截断账户列表拼合总额或重新计算数字；它只能解释本地引擎已经确认的完整科目集合。
- 一个词可能同时命中大科目、复合指标和小科目时，优先完整SAP编码，其次完整小科目名称，再次已确认复合指标；仍有多个有效口径时必须向用户提问。
- 同一SAP编码在两个管理大科目出现时，必须分别保留并按管理大科目选择，禁止仅按编码去重或跨管理行自动求和。
- 不允许用0代替缺失。没有完整科目集合、正式来源或分子分母时，应显示缺少数据或请求确认。

## 3. 稳定计算公式

```text
单台制造费（€/台） = 制造费（K€） × 1000 ÷ 产量（台）
制造费率 = 制造费（K€） ÷ 产值（K€）
累计单台（€/台） = 累计制造费（K€） × 1000 ÷ 累计产量（台）
整体单台（€/台） = （CK制造费 + DW制造费）×1000 ÷（CK产量 + DW产量）
整体费率 = （CK制造费 + DW制造费）÷（CK产值 + DW产值）
变化率 = （本期 − 基准）÷ |基准|
单台差异 = 本期单台 − 比较基准单台
单台同比幅度 = （本期单台 − 同期单台）÷ |同期单台|
单台环比幅度 = （本月单台 − 上月单台）÷ |上月单台|
降费额（K€） = （同期单台 − 本年单台）× 本年月产量 ÷ 1000
金额影响（万欧） = |本期单台 − 基准单台| × 本期产量 ÷ 10000
数量差异率 = （本期产量 − 同期产量）÷ 同期产量
```

- CK、DW合计必须先合并分子和分母再计算单台、费率或效率，禁止平均两个工厂的比率。
- 本年单台和同期单台必须分别使用本年金额/本年产量、同期金额/同期产量计算；不得用本年产量同时除本年和同期金额。
- 比率、差异和金额影响使用未四舍五入源值计算，最后才按页面格式显示。
- 基准为0、负数或缺失时，不强算百分比；直接说明无法形成可靠比例。
- 箭头只表示数学方向。“改善/恶化”必须结合指标性质和比较基准判断。

## 4. 固定费用与变动费用

固定费用包括：折旧（含FC）、运营费用、存货跌价准备、固定能源、间接人工、白领固定人工、半固定班车/工装及分配费用总计。

变动费用包括：直接人工、报废及可回收废料相关费用、生产耗材、废料收入/回收收益、变动能源。

- 固定费用 + 变动费用应与制造费用总额勾稽。
- 分配费用下的 IT、Association dues、G&A 等子项可以展示和核对，但总计只使用“分配费用总计”一次。
- 主段、GMA/外围段及明细同样不得重复进入制造费总额。
- “折旧实际需要叠加FC”是取数规则；“折旧属于固定费用”是分类规则，不能混为一件事。
- 旧口径“固定=折旧、变动=制造费总额−折旧”已失效。

## 5. 人工分析

- 直接人工、间接人工、白领人工分别汇总所属大科目的公司人工成本，再除以对应人数计算公司成本人均。
- 工资人均先合并同类工资小科目，再除以对应人数。某个工资小科目上月为0、本月出现时，先提示科目组成变化、重分类或计提线索，不能单独认定为新增人工成本。
- 人工金额变化至少同时看：公司成本人均、工资人均、人数、工作日和明显变化月份。
- 人工人均不等于实发工资；人数可能是FTE、月均或时点人数，必须核实范围。
- 可核实原因包括工时、加班、人员结构、工资标准、汇率、计提、冲回和重分类。缺少证据时写“需要核实”，不得断言根因。
- 下级小科目异常不自动证明上级大科目净额异常；要保留同类科目之间的抵消，影响金额不得在大小科目间重复加总。

### G&A管理费用人工的边界

- G&A / GMA / 外围段的 `Fixed Labour` 与制造费主段“固定人工-白领”是不同业务区域。回答时必须先确认区域，禁止把两者合并或相互替代。
- 当前问答证据包含G&A白领人工六类组成科目的逐月金额，可回答费用总额、同期差异和月度明细；不含月度有效人数和个人薪资字段，因此不能计算个人工资、白领工资人均或把分配FTE当自然人数。
- Basic Memory保留一份原始实际报表核对记录：DW 2026年1—7月G&A `Fixed Labour` 月度为23.02392、19.75755、22.75825、61.35179、18.36955、24.62323、20.51847 K€，累计190.40276 K€；2025年同期96.66429 K€，增加93.73847 K€、+96.973215%，其中4月为主要异常月。该记录只能在问题明确指向“DW、G&A、Fixed Labour、2026年1—7月”时作为历史核对结果引用，并注明来源是原始实际报表核对记录，不得冒充当前三张表的实时计算。
- G&A白领人工的正式逐月回答应使用原始G&A实际明细，并列示月份、费用、有效人数、公司成本人均、工资人均、环比、累计值和异常月份；目前缺少工资与有效人数时，要明确写“无法可靠计算人均”。

## 6. 产量和业务量可比分析

- 变动费用优先看单台和产量调整后差异；固定费用单台变化主要反映产量分摊，不等于固定费用总额本身恶化。
- 当前环比可比测算：以上月单位费用乘本月业务量得到业务量可比基准；本月实际与该基准的余额为调整后差异。
- 调整后差异只是测算项，仍可能包含工时、产品结构、价格、费率、汇率、停机和计提，不能直接称为效率损失。
- 直接人工虽归类为变动费用，但短期固定人员、闲置工时、加班和产品组合会使其不与产量严格同比例。需要标准工时和费率后才能做正式弹性预算。
- 餐费应匹配实际用餐人次；班车应匹配车次、线路和合同；不能把核心员工人数机械等同于全部驱动量。

## 7. 异常与经营关注

分析顺序：

1. 总体单台制造费及产量变化。
2. 固定费用和变动费用对总差异的贡献。
3. 直接人工、间接人工和白领人工的人均变化。
4. 与产量有关的费用在剔除产量影响后的调整差异。
5. 金额影响较大的大科目，再下钻到中文小科目。
6. 连续数月同方向变化、零/非零切换、异常峰值和科目组成变化。
7. 给出需要责任部门核实的原因清单。

当前月度数据较短，规则、控制图或预测残差可用于提示异常，但不能把异常分数当成会计因果。正式变点、异常检测和因果模型需要更长且可比的历史数据、可靠驱动和滚动回测。

## 8. 数据空白与可追溯性

- 制造费、产量、产值、人数、工作日和UPPH分别使用正式来源，不互相反推。
- 收入/产值缺失时，制造费率保持空白。
- 人数或工作日缺失时，不用预测值冒充实际，也不计算依赖这些驱动的实际UPPH或人均结论。
- 未来月实际保持空白，不用计划或预测补齐。
- 管理调整必须记录月份、基准版本、金额、产量和固定/变动分配，不能覆盖已关账实际。
- ACE/Kaizen项目收益、制造费科目差异和PPT降费叙述不是天然同口径，不机械对平，也不互相反推。

## 9. 回答规范

- 累计或区间问题必须先把请求范围内每个月逐月列全，再给累计值、结论、最关键的金额、人均/单台、环比及异常月份；不能只回答截止月，也不能把逐月数字埋在一整段文字中。
- 人工区间表至少列示公司人工成本、人数、公司成本人均、工资成本、工资人均和人均环比；费用区间表至少列示费用金额、产量、单台和环比。
- 逐月表由本地确定性引擎提供时，不重复改写或重新计算表中数字；在表后按“结论、主要变化、待核实”总结。
- 页面以环比为主；用户未要求时不要用同比替代环比。
- 只显示中文科目名称，不显示SAP编码。
- 数字必须来自随问题发送的本地证据；知识库只提供公式、分类和解释边界。
- 说明结论属于“已计算事实”“测算线索”还是“待核实原因”。
- 数据不足、口径不唯一或问题拿不准时，列出可提供的指标或让用户选择，不静默回退到制造费用总额。
- 不输出冗长方法说明，优先列出3—5个最重要问题。
